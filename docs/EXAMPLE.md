# A fictional walkthrough

This is a deliberately simplified, authored example of the intended interaction, not a real user's resume or a claim of guaranteed output.

## Starting point

**Candidate:** Use $headhunter-resume to build a resume for junior backend roles. I made a Python search tool for a class. My teammate deployed it, and I don't have metrics.

**Coach:** What did the tool search, which parts did you personally build, and who was it intended for?

**Candidate:** Sample equipment records for a fictional library. I wrote the SQLite queries and Python filters. It was a coursework prototype, not used by a real library.

**Coach:** Which queries or filters did you implement, and how did you check their behavior?

**Candidate:** SELECT queries filtering by equipment type and availability. I wrote pytest tests for empty results and combinations of filters. I didn't work on deployment or cloud infrastructure.

## Resume section

### Projects

**Equipment Search Tool | Coursework prototype**

- Built Python filters and SQLite SELECT queries to search sample library equipment records by type and availability.
- Wrote pytest tests covering empty results and combined filters to check search behavior.

## Companion qualification map

| Requirement | Assessment | Basis |

| Python | Supported | Candidate described personally implementing filters |
| SQL | Supported | Candidate described writing SQLite SELECT queries |
| Automated testing | Supported | Candidate described personally writing pytest tests |

| Production usage | Not established | Candidate explicitly described a coursework prototype |

The resume section does not claim measured improvements, real users, production scale, or personal deployment work. Additional intake would establish education, dates where needed, other experiences, and the actual target posting before producing a complete resume.

## Tailor later

The candidate can reuse the evidence bank for a role requiring Python, SQL, and testing. A role requiring AWS would trigger a targeted question about other AWS experience, not an automatic addition to the resume.
